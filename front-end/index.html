Pick up a note

Every note you drop gets a 6-character pickup code. Enter that code here to read the note again. Your browser asks API Gateway, Lambda looks the code up in DynamoDB, and the note comes back.

  1. Drop a noteWrite a message above and press Drop note. You get a code.
  2. Keep the codeCopy it, or send it to a friend. Anyone with the code can read the note.
  3. Pick it upEnter the code below. The code from your last drop is already filled in.
